# Artifact classification

Audited at: `8999ec3678b7f894a3547b1a930802a1adfe90a0`

> Historical evidence only; not current capability authority. Later outcomes
> are listed in the [audit index](README.md).

This inventory is the Phase A artifact census required by #9. The production
source authority is that commit; the audit base
is `b73fd39f3eb271d9d287f5927df41d99bd017a63`, which adds only the public-API
snapshot. It treats current source, manifests, executable tests and that
snapshot as authority.
An artifact is classified exactly once:

- **Valid**: current API and stated scope were verified at this revision.
- **Salvageable**: useful intent/source remains, but it is not a verified
  current user-facing baseline without rerun or substantial rewrite.
- **Historical**: revision- or migration-specific evidence; retain only if
  clearly archived as history/ADR.
- **Misleading**: presented as current while containing a demonstrated stale
  API, authority, support, or performance claim.

Verification completed for this census:

- `cargo check --offline --workspace --all-targets` passes, so every tracked
  Rust example and benchmark compiles at this authority.
- default workspace tests and doctests pass from the preceding clean-build
  census; `tenet/src/tutorial.md` is included into crate rustdoc and its Rust
  blocks are doctested.
- existing Julia scripts and recorded outputs were not accepted as current:
  their TensorKit environments/results are old or not pinned to the source
  revision represented by the output.
- no historical timing is treated as a current performance claim merely
  because its harness still compiles.

Phase B subsequently revalidated the TensorKit semantic oracle with Julia
1.11.6 and TensorKit main `f87ca7f` (Project version 0.17.1). Its numerical
output is unchanged; the committed Project/Manifest and SHA-256 file now bind
the source, dependency graph, and result.

## Immediate consequences

Current counts after the Phase B oracle revalidation: **22 Valid, 16
Salvageable, 9 Historical, 5 Misleading**.

1. Do not update README or claim competitive performance from the five
   Misleading artifacts; remove or rewrite their current-facing role first.
2. Historical issue evidence should not be deleted blindly, but must move out
   of the normal current-documentation path or gain an explicit historical
   banner.
3. Phase B may reuse Salvageable oracle/harness logic only after repinning,
   correctness validation and current-path confirmation.
4. Rust source compiling under `--all-targets` proves API freshness only; it
   does not promote an internal timing probe to a representative benchmark.
